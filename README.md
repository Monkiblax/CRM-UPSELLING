# CRM UPSELLING

Pipeline de Upsell: tablero Kanban (arrastrable) y vista de lista paginada para dar seguimiento a oportunidades de upsell.

## Etapas

Lead → Lead asignados → Appointment → Preparación → Propuesta → Negociación → Invoice → Pagado → Suscripción

## Uso

Es un archivo HTML autocontenido (`index.html`, sin build ni dependencias). Ábrelo directo en el navegador.

## Notas

- Soporta tema claro/oscuro (sigue `prefers-color-scheme`).
- Fuentes de Google Fonts: Archivo, Work Sans, IBM Plex Mono.
